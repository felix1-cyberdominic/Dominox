Play

Add a domino tile by entering the left and right pip values (0–12). Use Tab to navigate and Enter to submit.

Tiles are presented as buttons. Activate (Enter/Space) to flip, Delete to remove focused tile. Use Left/Right arrows to move focus between tiles.

About Dominox

Dominox is a small demo application intended to show an accessible frontend you can deploy on Vercel. It's intentionally lightweight (no frameworks) and built with accessibility best practices: landmarks, keyboard support, clear focus styles, and semantic markup.

Accessibility features

  • Skip link to main content
  • Keyboard navigation for tiles (Left/Right, Enter/Space, Delete)
  • ARIA roles and labels for assistive tech
  • High-contrast colors and visible focus outlines

Deploy

To deploy the frontend on Vercel: see the repository README or the Vercel docs. The site is static and will deploy automatically when you import this repository into Vercel.
